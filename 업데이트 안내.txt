방향 · GitHub Pages 업데이트

1. 압축을 풉니다.
2. 아래 세 파일을 ian-develop/goal 저장소의 기존 index.html과 같은 위치에 함께 올립니다.
   - index.html
   - banghyang-home-로 시작하는 PNG 파일
   - apple-touch-icon.png
3. GitHub Pages에 반영되면 Safari에서 https://ian-develop.github.io/goal/ 을 다시 엽니다.
4. 공유 → 홈 화면에 추가 화면의 미리보기에서 별 아이콘을 확인합니다.

기존 홈 화면 앱에 입력한 기록은 먼저 설정과 백업에서 내려받으세요.
새 홈 화면 앱에서 기록을 확인하기 전까지 기존 앱은 유지하세요.
이 묶음은 업데이트 준비 파일이며, GitHub에는 아직 업로드되지 않았습니다.

변경 내용
- 홈 아이콘 PNG를 HTML에서 직접 연결하고, 이미지 버전을 파일명으로 구분합니다.
- 월간·분기·반기·연간을 해당 주기 이름과 전체 기간으로 표시합니다.
- 목표 상세 통계도 해당 목표 주기로 열리며 이전·다음 이동이 일치합니다.
- 설정과 백업 → 통계 시작 주에서 원하는 시작 주를 선택하고 저장합니다.
- 선택한 주의 월요일~일요일을 1주차로 표시하며, 시작 이전은 통계에서 제외합니다.
- 2026년 10월 첫 월요일은 10.5입니다. 1주차는 10.5~10.11, 첫 월간 집계는 10.5~10.31입니다.
- 기존 9.21 설정은 직접 바꾸기 전까지 유지합니다. 시작 주를 바꿔도 기존 기록은 삭제하지 않습니다.
- 월·분기 등의 누적기간 중간으로 시작일을 옮기면 새 첫 구간의 누적값은 다시 입력합니다.
- 기록은 같은 기기와 같은 브라우저에 계속 저장됩니다.
